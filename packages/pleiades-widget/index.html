Pleiades widget — dev page

Edit anything in src/ — the page reloads at once and the panel stays open. Settings go in the URL: ?agent-url=…&publishable-key=pk_…&lang=en&position=bottom-right&dark, or in .env.local as VITE_PLEIADES_URL and VITE_PLEIADES_PUBLIC_KEY. Without them the chat talks to a built-in mock API (dev/mock-api.ts). Try the words steps, slow, error, fail, tool.
