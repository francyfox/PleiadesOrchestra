# PleiadesOrchestra

PleiadesOrchestra — чат-ассистентке бір үлкен хостингтегі модельдің орнына **шағын локалды модельдер** арқылы веб-сайтты басқаруға мүмкіндік беретін шағын сервистер жиынтығы. Не істеу керектігін GOAP планировщигі (goal-oriented action planning, мақсатқа бағытталған әрекеттерді жоспарлау) шешеді; модельдер тек тар міндеттерді орындайды: хабарламаны жіктеу, құралдың аргументтерін толтыру, қысқа жауап жазу.

Жүйе бір ғана сайт түріне арналмаған. Дүкен, қонақүйді брондау формасы, пицца конструкторы немесе билет анықтамасы — бәрі бірдей жұмыс істейді: сайт өзінің не істей алатынын сипаттайды, ал оркестратор сол сипаттама бойынша жоспар құрады.

## Қалай жұмыс істейді

1. Сайт [`<pleiades-chat>` виджетін](/docs/widget/) енгізеді.
2. Сайт өз құралдарын браузерде WebMCP арқылы тіркейді (`document.modelContext.registerTool`). Құрал — атау, сипаттама және JSON-схема. [Құралдар](/docs/tools/) бөлімін қараңыз.
3. Панель ашылғанда виджет құралдар каталогын оркестраторға жібереді (`POST /v1/widget/tools`). [Widget API](/docs/api/widget/) бөлімін қараңыз.
4. Келуші хабарлама жазады. Оркестратор келушінің не қалайтынын анықтайды, құрал шақыруларының тізбегін жоспарлайды және барысын NDJSON ретінде ағынмен қайтарады.
5. Құралдар **келушінің браузерінде** орындалады. Жоспарға құрал қажет болғанда ағын `tool_call` жолымен аяқталады; виджет құралды бетте орындап, нәтижесін кері жібереді, сонда жұмыс жалғасады.

Оркестратор сайттың кодын да, дерекқорын да көрмейді: тек құрал атауларын, схемаларын және құралдардың жауаптарын көреді.

## Сервистер

| Сервис | Рөлі |
| --- | --- |
| `alpha-orchestrator` | HTTP-сервис. Арналарды, келушілерді, тредтер мен тарихты (SQLite) сақтайды, GOAP планировщигін іске қосады және жауаптарды ағынмен береді. Widget API мен server API осы жерде сипатталған. |
| `beta-text` | Шағын жауап моделі бар `llama-server`. Сөйлесу жауабын жазады. |
| `gamma-decision` (Laya) | Типтелген шешімдер үшін қосалқы сервис. Таңдау және баға туралы сұрақтарға калибрленген ықтималдықтармен жауап береді; мәтін жазбайды. Ниетті жіктеу үшін және құралдың нұсқаларының арасынан таңдау үшін қолданылады. |
| `delta-function-call` | Келушінің хабарламасы мен құрал схемасы бойынша құрал шақыруының JSON-аргументтерін толтыратын шағын `llama-server`. |
| alpha-understand | Жеке сервис емес: әр хабарламаға `alpha-orchestrator` жасайтын тіл моделінің бір шақыруы. Ол хабарламаны ағылшынша жазады, тапсырмаларға бөледі және әр тауардың санын белгілейді; шешім және функция шақыру модельдері тек ағылшын тілін оқиды. |

Әр модель сервисі сол машинада немесе басқа жерде жұмыс істей алады; `alpha-orchestrator` оған базалық URL арқылы қосылады.

## Беттер

- [Виджет](/docs/widget/): `<pleiades-chat>` орнату және баптау.
- [Құралдар](/docs/tools/): сайт құралдарды WebMCP арқылы қалай ашады.
- [Widget API](/docs/api/widget/): виджет қолданатын REST және NDJSON API.
- [Server API](/docs/api/server/): серверден серверге арналған эндпоинттер.
- [Ниеттер](/docs/intents/): хабарлама қалай жіктеледі және не жоспарланады.
