# CLI (`albedo`)

`albedo` — оркестратордың шағын консольдік клиенті: хабарлама жіберу, ағынды тазалау, қызметкер аккаунтын құру, сапа тексерулерін іске қосу. Оның өз логикасы жоқ: ол [Server API](/docs/api/server/) шақырады (әкімшілік көмекшілер үшін Docker).

## Қайдан алуға болады

- **Образда:** `albedo` `ghcr.io/francyfox/pleiades` ішіне жиналған, сондықтан серверде оны контейнерде іске қосады: `docker exec pleiades albedo help`. `HARNESS_BASE_URL` онда бұрыннан берілген, ал `HARNESS_API_KEY` контейнердің `.env` файлынан алынады.
- **Дайын бинарь:** әр [GitHub релизінде](https://github.com/francyfox/PleiadesOrchestra/releases) Linux (`x64` және `arm64`, сондай-ақ Alpine үшін `-musl` жинақтары) және macOS (`darwin-x64`, `darwin-arm64`) үшін `albedo` және бақылау сомалары файлы бар. Жүйеңізге сәйкесін жүктеп, `chmod +x` жасап, `PATH` ішіне қойыңыз.
- **Репозиторийден:** `scripts/install-albedo.sh` Bun арқылы бір бинарь жинап, `~/.local/bin` ішіне сілтеме қояды; немесе бастапқы кодтан: `bun --cwd apps/cli start <команда>`.

## Орта

| Айнымалы | Мақсаты |
| --- | --- |
| `HARNESS_API_KEY` | Оркестратордың транспорттық кілті. `send` және `reset` үшін міндетті. |
| `HARNESS_BASE_URL` | Оркестратор мекенжайы. Әдепкі `http://localhost:3000`. |
| `PLEIADES_VERSION` | `albedo --version` басатын стек нұсқасы; болмаса CLI-ға кіріктірілген нұсқа алынады. |

## Командалар

Әр команданың қысқа түрі бар.

| Команда | Қысқа | Не істейді |
| --- | --- | --- |
| `send` | `s` | Хабарлама жібереді (`-m`) және жауапты ағынмен шығарады; `-t` ағын, `-u` пайдаланушы. `-a alpha\|beta\|delta` бір агенттің моделін жеке сұрайды, `-a gamma -q "сұрақ"` шешім агентін сұрайды (таңдау үшін `--options a,b,c`). |
| `reset` | `r` | Ағын тарихын тазалайды (`-t`). |
| `admin:create` | `ac` | Қызметкер аккаунтын немесе бар аккаунт үшін жаңа токен құрады (`--email`, `--name`, `--level 0\|100`). Токен бір рет басылады. Admin API-ді өзі табады: бір пәрмен орнатудағы `pleiades` контейнері, әзірлеу кезінде compose қызметі немесе образ ішінде іске қосқанда образдың өз бинарі. |
| `eval` | `e` | Іске қосылған оркестратор қолданатын модельдермен сапа тексеруін жүргізеді (`--name intents\|tools\|choose-tool\|answers\|decompose`). Репозиторий көшірмесі қажет. |
| `help` | `h` | Командаларды опцияларымен көрсетеді. |

`albedo -v` (`--version`) нұсқаны басады, `albedo -h` (`--help`) — `help` сияқты тізім.

```sh
albedo send -m "Сен не істей аласың?" -t demo
albedo s -m "сәлем" -a beta
albedo ac --email you@example.com
albedo e --name answers
```
