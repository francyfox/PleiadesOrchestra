# PleiadesOrchestra

PleiadesOrchestra — набор небольших сервисов, которые позволяют чат-ассистенту управлять сайтом с помощью **небольших локальных моделей** вместо одной крупной облачной. Что делать, решает GOAP-планировщик (goal-oriented action planning, целеориентированное планирование действий); модели выполняют только узкие задачи: классифицируют сообщение, заполняют аргументы инструмента, пишут короткий ответ.

Система не рассчитана на один тип сайта. Магазин, форма бронирования отеля, конструктор пиццы или касса билетов работают одинаково: сайт описывает, что он умеет, а оркестратор строит план вокруг этого описания.

## Как это работает

1. Сайт встраивает [виджет `<pleiades-chat>`](/docs/widget/).
2. Сайт регистрирует собственные инструменты в браузере через WebMCP (`document.modelContext.registerTool`). Инструмент — это имя, описание и JSON-схема. См. [Инструменты](/docs/tools/).
3. Когда панель открывается, виджет отправляет каталог инструментов оркестратору (`POST /v1/widget/tools`). См. [Widget API](/docs/api/widget/).
4. Посетитель пишет сообщение. Оркестратор определяет, чего хочет посетитель, строит последовательность вызовов инструментов и передаёт прогресс потоком NDJSON.
5. Инструменты выполняются **в браузере посетителя**. Когда плану нужен инструмент, поток завершается строкой `tool_call`; виджет выполняет инструмент на странице и отправляет результат обратно, после чего запуск продолжается.

Оркестратор никогда не видит код или базу данных сайта — только имена инструментов, схемы и ответы инструментов.

## Сервисы

| Сервис | Роль |
| --- | --- |
| `alpha-orchestrator` | HTTP-сервис. Хранит каналы, посетителей, треды и историю (SQLite), запускает GOAP-планировщик и передаёт ответы потоком. Widget API и Server API описаны здесь. |
| `beta-text` | `llama-server` с небольшой моделью для ответов. Пишет разговорный ответ. |
| `gamma-decision` (Laya) | Sidecar для типизированных решений. Отвечает на вопросы выбора и оценки откалиброванными вероятностями; текст не пишет. Используется для классификации намерений и для выбора среди вариантов инструмента. |
| `delta-function-call` | Небольшой `llama-server`, который заполняет JSON-аргументы вызова инструмента по сообщению посетителя и схеме инструмента. |
| translator | Не отдельный сервис: нативный движок Opus-MT (CTranslate2) внутри `alpha-orchestrator`. Модели решений и вызова функций читают только английский, поэтому сообщения на других языках сначала переводятся. |

Каждый сервис с моделью может работать на той же машине или на другой; `alpha-orchestrator` обращается к нему по базовому URL.
