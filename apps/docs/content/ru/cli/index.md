# CLI (`albedo`)

`albedo` — небольшой консольный клиент оркестратора: отправить сообщение, сбросить ветку, создать аккаунт сотрудника, запустить проверки качества. Своей логики у него нет: он вызывает [Server API](/docs/api/server/) (и Docker для админских помощников).

## Где взять

- **В образе:** `albedo` собран в `ghcr.io/francyfox/pleiades`, поэтому на сервере его запускают в контейнере: `docker exec pleiades albedo help`. `HARNESS_BASE_URL` там уже задан, а `HARNESS_API_KEY` берётся из `.env` контейнера.
- **Готовый бинарник:** в каждом [релизе на GitHub](https://github.com/francyfox/PleiadesOrchestra/releases) лежит `albedo` для Linux (`x64` и `arm64`, а также сборки `-musl` для Alpine) и macOS (`darwin-x64`, `darwin-arm64`) и файл контрольных сумм. Скачайте под свою систему, сделайте `chmod +x` и положите в `PATH`.
- **Из репозитория:** `scripts/install-albedo.sh` собирает один бинарник через Bun и ставит ссылку в `~/.local/bin`; либо запуск из исходников: `bun --cwd apps/cli start <команда>`.

## Окружение

| Переменная | Назначение |
| --- | --- |
| `HARNESS_API_KEY` | Транспортный ключ оркестратора. Обязателен для `send` и `reset`. |
| `HARNESS_BASE_URL` | Адрес оркестратора. По умолчанию `http://localhost:3000`. |
| `PLEIADES_VERSION` | Версия стека, которую печатает `albedo --version`; без неё берётся версия, встроенная в CLI. |

## Команды

У каждой команды есть короткая форма.

| Команда | Коротко | Что делает |
| --- | --- | --- |
| `send` | `s` | Отправляет сообщение (`-m`) и выводит ответ потоком; `-t` ветка, `-u` пользователь. `-a alpha\|beta\|delta` спрашивает модель одного агента отдельно, `-a gamma -q "вопрос"` — агента решений (`--options a,b,c` для выбора). |
| `reset` | `r` | Очищает историю ветки (`-t`). |
| `admin:create` | `ac` | Создаёт аккаунт сотрудника или новый токен для существующего (`--email`, `--name`, `--level 0\|100`). Токен печатается один раз. Админ-API находит сам: контейнер `pleiades` из установки одной командой, сервис compose при разработке или собственный бинарь образа, если запуск внутри образа. |
| `eval` | `e` | Запускает проверку качества (`--name intents\|tools\|choose-tool\|answers\|decompose`) на моделях, которые использует запущенный оркестратор. Нужен чекаут репозитория. |
| `help` | `h` | Показывает команды с их опциями. |

`albedo -v` (`--version`) печатает версию, `albedo -h` (`--help`) — тот же список, что и `help`.

```sh
albedo send -m "Что ты умеешь?" -t demo
albedo s -m "привет" -a beta
albedo ac --email you@example.com
albedo e --name answers
```
